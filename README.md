# GenAI-Powered Enterprise Service Desk Agent

A beginner-friendly IT support ticket management project that will gradually evolve into an AI-powered service desk application.

## Current Features

- Create IT support tickets
- Enter employee name and issue description
- Select issue category and priority
- Generate ticket IDs
- Display ticket status
- Show ticket creation date and time
- Track total and open tickets

## Tech Stack

- HTML
- CSS
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Create a support ticket using the form.

## Roadmap

- Ticket search and filtering
- Ticket status management
- Local storage and database integration
- React frontend
- Node.js and Express backend
- AI-based ticket classification
- Knowledge-base question answering
- Human support escalation
